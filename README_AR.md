# SHOKR — منصة الأعمال الرقمية

## تشغيل الموقع من الهاتف
1. نزّل ZIP وفك الضغط باستخدام مدير الملفات.
2. افتح GitHub وأنشئ مستودعًا جديدًا باسم `shokr-platform`.
3. اجعل المستودع Public إن كنت تريد استخدام GitHub Pages المجاني.
4. اضغط Add file ثم Upload files وارفع `index.html` و`style.css` و`script.js` إلى جذر المستودع.
5. اضغط Commit changes.
6. افتح Settings ثم Pages.
7. اختر Deploy from a branch، ثم `main` و`/(root)`، واضغط Save.
8. افتح رابط الموقع الذي يظهر في صفحة Pages.

## رقم واتساب
في `script.js` غيّر `201070424120` إلى رقم دعم هذا المشروع بصيغة دولية بدون + أو مسافات.

## حدود النسخة الأولى
هذه واجهة Front-end احترافية؛ نموذج التواصل يفتح واتساب ولا يحفظ الطلبات في قاعدة بيانات. تسجيل الحسابات، قاعدة البيانات، الدفع الإلكتروني ولوحة الإدارة تحتاج إضافتها في مرحلة تالية. أمثلة المشاريع المعروضة تصميمات توضيحية وليست أعمال عملاء حقيقية.
